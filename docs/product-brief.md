# Product Brief

## Purpose

The Adaptive Wellness Coach will demonstrate practical skills in AI tool use, personalization, product design, safety, structured data, testing, and evaluation.

## Target User

The first version is for generally healthy people who are complete beginners or returning to exercise and need help building a realistic routine.

## User Problem

Generic fitness advice often ignores a person's experience, schedule, equipment, preferences, and previous results. Users need a structured plan that fits their situation and clearly explains its recommendations.

## First-Version Goal

The first version will collect a structured user profile, validate required information, screen for excluded safety situations, and create a basic seven-day workout plan for an eligible fictional user.

## Required Inputs

- Experience level
- Primary fitness goals
- Current activity level
- Available workout days
- Time available per session
- Preferred workout structure
- Available equipment
- Preferred activities
- Disliked activities
- Preferred workout intensity
- Safety-screening responses

## Planned Outputs

- Safety eligibility result
- Structured seven-day schedule
- Workout type and duration
- Exercises or activities
- Intended intensity
- Rest guidance
- Equipment alternatives when appropriate
- Short explanation of the recommendations
- Weekly activity totals

## Differentiation

This will not be a generic fitness chatbot. It will use structured intake, separate beginner and returning-user modes, explicit safety screening, consistent output formats, transparent rules, reliable Python functions, repeatable tests, and documented failure handling.

## First-Version Success

The first version succeeds when it can safely create and explain a realistic weekly workout plan for different fictional users while respecting their stated constraints. Feedback-based adjustment will be evaluated in a later sprint.

## Out of Scope for the Initial Version

- Meal and snack suggestions
- Calorie estimates
- Medical advice or symptom assessment
- Injury rehabilitation
- Pregnancy or postpartum workout planning
- Eating-disorder support
- Chronic-condition management
- Wearable-device integration
- Exercise-form analysis
- Real-time coaching
- Multiple AI agents
- Native mobile applications
- User accounts, payments, and social features
